# Teste simples dentro do jogo

Esta versão não é plugin. Ela permite testar o resultado no Roblox Studio sem criar um plugin local.

## Passos

1. Abra o Roblox Studio.
2. No Explorer, encontre `StarterPlayer`.
3. Abra `StarterPlayerScripts`.
4. Clique com o botão direito em `StarterPlayerScripts`.
5. Selecione `Insert Object > LocalScript`.
6. Renomeie para `GalaxDemo`.
7. Abra `game/StarterGuiGenerator.client.lua` deste repositório.
8. Copie todo o código e cole no LocalScript.
9. Clique em **Play** no Roblox Studio.

A GUI aparecerá durante o teste. Clique em **JOGAR** ou **FECHAR** para verificar os botões.

Importante: este script é apenas uma demonstração dentro do jogo. Ele não aparece na aba Plugins e não é uma IA real. O plugin do Studio é uma etapa diferente.
